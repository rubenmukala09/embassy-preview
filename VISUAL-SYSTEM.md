# Embassy visual system

## Project inventory

- 17 public routes
- 56 images and illustrations
- 111 buttons and button-like controls
- 69 form controls across 6 forms
- 1,071 links
- 4 embedded map or external frames
- Shared presentation layers: `aurora.css`, `enrichment.css`, and `responsive-control.css`

## Shared design language

The responsive control layer defines semantic color, spacing, radius, shadow,
focus, surface, and content-width tokens. It also provides safe media sizing,
text wrapping, keyboard focus visibility, reduced-motion support, minimum touch
targets, dark-surface contrast protection, and narrow-screen grid recomposition.

## Visual Control Studio

Append `?design=1` to any page URL to open the right-side Visual Control Studio.
It is never loaded into the visible experience for ordinary visitors.

The studio supports:

- selecting any visible page element;
- eight resize handles and a drag handle;
- layout, size, position, frame, crop, color, effects, typography, widget,
  responsive, animation, accessibility, and advanced panels;
- all-screen, tablet, and mobile override scopes;
- image object-fit and focal-point control;
- local undo, redo, reset, and saved drafts;
- WCAG-oriented contrast checks and alternative-text editing;
- copying selected CSS and a live page inventory for permanent source updates.

Keyboard shortcuts: `Alt+D` toggles the inspector, `Ctrl/Cmd+Z` undoes, and
`Ctrl/Cmd+Shift+Z` redoes.
